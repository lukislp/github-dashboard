# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability reporting:
https://github.com/lukislp/github-dashboard/security/advisories/new

If you cannot use GitHub's private reporting, email
[koerber.lukas@t-online.de](mailto:koerber.lukas@t-online.de) instead.

Do not open a public issue for security problems. You will get an acknowledgement within a few
days and a fix or mitigation plan before any public disclosure.

## Supported versions

Only the latest release receives security fixes.
